# SCC-functions
Azure functions para projeto de SCC.
Timer function existente é usada para terminar as auctions aquando o seu ending time chega ao limite. Atribuindo assim ao seu status a String de "CLOSED" e caso existam bids, atribui à auction o utilizador com o maior bid.
